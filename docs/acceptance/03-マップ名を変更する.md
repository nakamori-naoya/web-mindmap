# マップ名を変更する

名前を一度消して入力し直しても、意図した新しい名前だけが保存される。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

「名前変更」という保存済みマップを開いている。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. 上部のマップ名を全選択し、Backspaceで一度空にする。
2. 「NEW」と入力して入力欄からフォーカスを移す。
3. 保存済みを待ち、ページを再読込して一覧の名前も確認する。

## 期待する結果

- 入力結果が「NEW」となり、「無題のマップNEW」のように既定名が追記されない。
- 一覧と編集画面で同じ名前を表示し、再読込しても保持する。

## 失敗・取消・境界で守ること

- 名前の入力途中で画面を移ろうとした場合、未完成の入力を黙って失わない。
- 空の名前からフォーカスを移して確定すると「無題のマップ」になる。入力途中にはこの既定名を差し込まない。

## 確認方法と現在の状態

名前を全削除してから置換し、保存後の名前を確認する自動試験がある。対応する試験は[e2e/workflow-ux.spec.ts](../../tests/e2e/workflow-ux.spec.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

名前の最大長境界と、入力途中のブラウザ強制終了は未確認。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
