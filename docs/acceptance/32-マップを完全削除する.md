# 確認してマップを完全削除する

戻せない操作であることを理解し、確認した対象だけを画像ごと削除する。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

専用試験用マップをゴミ箱へ移している。実利用のマップは使わない。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. 対象の「完全削除」を押し、対象名と戻せない旨を確認する。
2. 確認を取り消した試行と、承認した試行を分ける。
3. 承認後に一覧とゴミ箱、対象の直接URLを確認する。

## 期待する結果

- 取消した場合は本文・画像を含む対象を保持する。
- 承認した場合は対象とその保存版・画像を残さず、通常の復元やUndoでは戻せない。
- 他のマップと画像を削除しない。

## 失敗・取消・境界で守ること

- ゴミ箱内でないマップを完全削除できない。
- 対象名が一致しない確認要求は拒否する。
- 失敗した場合は完了表示にせず理由を示す。

## 確認方法と現在の状態

マップ完全削除と画像の削除、所有範囲の試験がある。対応する試験は[images-api.test.ts](../../tests/images-api.test.ts)、[api.test.ts](../../tests/api.test.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

画面の確認取消から直接URL確認までの専用E2Eは未完了。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
