# ダーク・ライト・OS追従を切り替える

利用するテーマでも本文、枝、選択、フォーカスを読み分けられる。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

マップの編集画面または一覧を開いている。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. テーマをダークからライトへ変更する。
2. 本文編集、選択、書式パネル、検索、画像プレビューを開く。
3. OS追従へ切り替え、OSの配色に応じる条件を確認する。

## 期待する結果

- 背景、パネル、本文、補助文字、ボタンが同じテーマへ揃う。
- 選択枠とキーボードフォーカスを、本文と枝色から区別できる。
- 画像の内容自体をテーマ変更で反転させない。

## 失敗・取消・境界で守ること

- ダークとライトで文字が背景へ埋もれず、通常文字のコントラスト4.5:1を受け入れ基準とする。
- テーマ変更だけで保存済みマップの本文や画像を変えない。

## 確認方法と現在の状態

ダーク・ライト切替を含むブラウザ試験と画面探索記録がある。対応する試験は[e2e/editor.spec.ts](../../tests/e2e/editor.spec.ts)、[e2e/editor-ux.spec.ts](../../tests/e2e/editor-ux.spec.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

OS追従、全要素のコントラスト測定、スクリーンリーダーの実機確認は未完了。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
