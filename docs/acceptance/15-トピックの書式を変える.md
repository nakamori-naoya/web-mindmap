# 文字サイズ・枝色・方向を変更する

選択した枝の見た目を変え、保存・Undo後も画面と内容が一致する。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

複数の主枝を持つマップで一つの主枝を選び、書式パネルを開いている。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. 文字サイズ、用意された枝色、カスタム色を変更する。
2. 主枝の方向を左または右へ切り替える。
3. Undoを行い、保存後に再読込する。

## 期待する結果

- 選んだ書式と方向を適用し、画像・本文の領域や親子関係を壊さない。
- Undo後の入力欄とノード表示が、元に戻った値と一致する。
- 色だけに選択状態を依存させず、枠やフォーカスを見分けられる。

## 失敗・取消・境界で守ること

- 色パレットはデスクトップ32px角、タッチ画面44px角以上を確保してパネル内で折り返す。
- 長い本文や画像のあるノードでも枝、文字、操作ボタンが重ならない。
