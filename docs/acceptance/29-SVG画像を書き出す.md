# マップ全体をSVG画像として保存する

別の環境で元画像ファイルを探さず、文字・線・添付画像を表示できるSVGを保存する。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

画面外と折り畳み配下、添付画像を持つマップを開いている。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. 書き出し形式からSVGを選ぶ。
2. 保存したSVGを元マップとは別に開く。
3. 文字と曲線、添付画像を確認する。

## 期待する結果

- 全ノードと曲線を含み、本文はSVGの文字として保持する。
- 添付画像はデータとして埋め込み、外部URLやfile形式のパスを読み込まない。
- 元画像ファイルがない環境でも、SVG内の画像が表示される。

## 失敗・取消・境界で守ること

- 添付画像の本体が不足する場合は出力を中止して理由を示す。
- 本文に特殊文字やスクリプトらしい文字を書いても、出力からスクリプトを実行しない。
- foreignObjectだけに依存した文字表示にしない。

## 確認方法と現在の状態

画像data URI埋込、payload欠落拒否、特殊文字処理を確認する試験がある。対応する試験は[e2e/node-images.spec.ts](../../tests/e2e/node-images.spec.ts)、[io.test.ts](../../tests/io.test.ts)、[images-domain.test.ts](../../tests/images-domain.test.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

すべてのSVG閲覧ソフトとフォント置換による差は未確認。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
