# マップをゴミ箱へ移す

通常一覧からマップを外しても、復元できる内容と画像を保持する。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

本文・メモ・画像を持つ保存済みマップが通常一覧にある。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. 対象マップの「ゴミ箱へ移動」を押す。
2. 通常一覧から消えたことを確認し、ゴミ箱を開く。
3. 他のマップが変わっていないことを確認する。

## 期待する結果

- 対象は通常一覧から外れ、ゴミ箱に名前とともに現れる。
- 本文・順序・メモ・画像を完全削除せず、30日の復元対象として残す。
- 通常一覧にある別マップは変更しない。

## 失敗・取消・境界で守ること

- 移動が失敗した場合は理由と再試行できる状態を示し、移動完了と誤表示しない。
- ゴミ箱へ移す操作と、元に戻せない完全削除を同じボタンとして扱わない。

## 確認方法と現在の状態

ゴミ箱状態、通常一覧との区別、画像保持の保存/API試験がある。対応する試験は[storage.test.ts](../../tests/storage.test.ts)、[images-api.test.ts](../../tests/images-api.test.ts)、[api.test.ts](../../tests/api.test.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

カードの操作と失敗表示の専用E2Eは未網羅。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
