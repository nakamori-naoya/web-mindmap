# 左右配置と右向き配置を切り替える

同じマップの内容を変えずに、左右へ広げるマインドマップと右向きのロジックチャートを選べる。配置を見やすくする操作で、本文や画像の親子関係を変えないことを受け入れ条件とする。

## 操作前の状態

本人1人のローカル環境で、左右の主枝、複数の兄弟、長い本文、添付画像を持つ保存済みマップを開いている。書式パネルのレイアウト選択が使える。

## ユーザーの操作

1. レイアウトを「左右のマインドマップ」から「右向きロジックチャート」へ変更する。
2. 全体表示で図を確認し、左右配置へ戻す。
3. 保存してページを再読込する。

## 期待する結果

- 選択した配置へ枝を並べ直し、ノードの本文、順序、親子、メモ、画像を変更しない。
- 文字と画像の寸法、開閉・追加ボタンを含む領域が隣の枝と重ならない。
- 左右配置の主枝の向きは保存された側を尊重し、本文編集のたびに勝手に左右が入れ替わらない。
- 再読込後は選んだレイアウトで開き、全体表示で現在の図を見つけ直せる。

## 失敗・取消・境界で守ること

- 折り畳んだ配下は配置切替で削除しない。
- 文字編集中や画像取り込み中に操作を行う場合は、その入力や添付先を黙って失わない。
- 保存失敗中は、切替結果を保存済みと誤表示しない。

## 確認方法と現在の状態

配置の決定性、1000・5000ノードの非重複、画像領域の高さと左右割当は[配置試験](../../tests/layout.test.ts)と[画像配置試験](../../tests/images-domain.test.ts)の対象である。左右・右向きの実画面は探索評価で確認している。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。

長文・画像・折り畳み・編集中の状態をすべて組み合わせた配置切替と、切替直後の再読込の専用ブラウザ試験は未網羅である。このファイルの全条件を合格済みとは扱わない。実行結果は[検証記録](../verification-results.md)へ残す。
