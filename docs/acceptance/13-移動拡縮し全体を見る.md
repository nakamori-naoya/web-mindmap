# パン・ズーム・全体表示で図を見る

編集対象や全体を見つけ直せて、表示の操作が本文編集と衝突しない。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

画面外に枝が広がるマップで一つのトピックを選択している。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. 背景ドラッグ、通常スクロール、Spaceを保持したドラッグで表示位置を動かす。
2. ポインターを図の上に置き、修飾キー付きホイールまたは拡大縮小ボタンを使う。
3. 「全体表示」と「選択へ移動」を実行する。

## 期待する結果

- 通常スクロールはパン、修飾キー付き操作はポインター付近を基準に10〜300%で拡縮する。
- 全体表示で現在表示する木を余白付きで収め、選択へ移動で対象へ戻れる。
- Space保持中にドラッグした場合は、キーリピート後に離しても本文編集を始めない。

## 失敗・取消・境界で守ること

- 本文入力欄ではSpaceを文字として入力し、通常の文字選択・スクロールを奪わない。
- 縮小時も追加・開閉ボタンの操作領域を保ち、隣のノードへ重ならない。
