# マップ全体をPNG画像として保存する

画面外の枝と添付画像を含むマップ全体を、一枚のPNGへ書き出せる。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

画面外・折り畳み配下・添付画像を持つマップを開いている。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. PNG出力を選び、1xまたは2xの倍率を設定する。
2. 出力を実行し、ダウンロードした画像を開く。
3. 画面上の表示範囲と、出力画像の枝・日本語・添付画像を比較する。

## 期待する結果

- PNGとして開け、日本語・色・曲線・画面外と折り畳み配下のノードが欠けない。
- 添付画像の実際の画素が出力に含まれ、空白の画像枠だけにならない。
- 全体を4096×4096px以内へ収め、必要な縮小を案内する。

## 失敗・取消・境界で守ること

- 画像本体の取得や生成が失敗した場合は理由を示し、欠けた出力を成功扱いにしない。
- 画像取り込み中は完了まで待つ案内を出し、途中の内容を出力しない。

## 確認方法と現在の状態

PNG署名・寸法・添付画像色の実画素と、全体SVG生成の試験がある。対応する試験は[e2e/node-images.spec.ts](../../tests/e2e/node-images.spec.ts)、[e2e/editor.spec.ts](../../tests/e2e/editor.spec.ts)、[io.test.ts](../../tests/io.test.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

巨大図の文字の読める大きさ、全フォント・実端末の画像表示は保証せず未網羅。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
