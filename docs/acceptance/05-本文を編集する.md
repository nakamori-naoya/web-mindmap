# 本文を編集し、確定または取り消す

編集中の長文と改行を見渡しながら、日本語を欠かさず入力し、確定と取消を区別できる。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

短い本文を持つ既存トピックを選択している。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. F2、Spaceの押して離す操作、またはダブルクリックで編集を始める。
2. 日本語5行と連続する長文を入力し、上下キーと欄内スクロールで見直す。
3. Enterで確定する試行と、Escapeで取り消す試行を別々に行う。

## 期待する結果

- 入力中から幅・高さが本文に追随し、元が1行でも1行分しか見えない状態に固定されない。
- 画面より長い本文は画面内の複数行欄でスクロールでき、キャレットとフォーカスを失わない。
- Shift+Enterは改行、Enterは確定、既存本文のEscapeは編集開始時の本文へ戻す。
- 選択状態で通常の文字を入力すると置換として編集を開始できる。

## 失敗・取消・境界で守ること

- 日本語変換中のEnter・Tab・Escapeで枝を追加・削除せず、変換確定のEnterを構造操作として扱わない。
- 本文は2000文字までとし、2001文字の確定では理由を示してドラフトを残す。
- 空の既存本文は「トピック」、空の中心は「中心トピック」として確定する。
