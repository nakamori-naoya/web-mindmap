# 保存したマップを開く

一覧または直接URLから目的のマップを開き、保存した内容を読み続けられる。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

本文、順序、メモ、画像のある保存済みマップを用意して一覧を開いている。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. 目的のマップのカードを押す。
2. 一覧へ戻り、同じマップをもう一度開く。
3. 編集画面のURLを使ってページを再読込する。

## 期待する結果

- 目的のマップ名と中心、保存した枝が表示され、別のマップの内容に入れ替わらない。
- 本文、枝の順序、書式、メモ、添付画像、折り畳み状態を失わない。
- 保存済みの内容だけを示す場合に「保存済み」と表示する。

## 失敗・取消・境界で守ること

- 見つからないマップや読み込み失敗は、画面で理由と戻る・再試行の手段を示す。
- ゴミ箱内のマップを通常のマップ一覧のカードから編集状態で開かない。

## 確認方法と現在の状態

再読込による本文・メモ・画像保持、および保存層の再起動保持を確認する試験がある。対応する試験は[e2e/editor.spec.ts](../../tests/e2e/editor.spec.ts)、[e2e/node-images.spec.ts](../../tests/e2e/node-images.spec.ts)、[storage.test.ts](../../tests/storage.test.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

存在しない直接URLとネットワーク失敗の画面回復手順は追加の手動確認が必要。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
