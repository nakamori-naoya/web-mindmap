# トピックを選び、選択を移動・追加する

見えている木の親子・兄弟を選び分け、複数選択した対象を確認できる。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

中心、左右の主枝、子と兄弟、折り畳んだ枝を持つマップを開いている。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. トピックをクリックし、矢印で内側・外側・上下へ選択を移す。
2. Shift+クリックで別トピックを追加し、もう一度同じ対象をShift+クリックする。
3. Shiftを押しながら背景を矩形ドラッグして複数選択する。

## 期待する結果

- 選択中の対象が枠で分かり、文字編集状態とは区別できる。
- 内向きは親、外向きは最初の子、上下は同階層の前後を基本とし、左右の配置を尊重する。
- 折り畳みで隠れたノードへ選択が飛ばない。
- 追加選択・解除・矩形選択の結果が画面で分かる。

## 失敗・取消・境界で守ること

- 中心を含む選択でも、中心を削除・親変更できる状態にしない。
- 親子を重複選択してコピー・削除した場合、同じ配下へ二重に操作しない。

## 確認方法と現在の状態

矩形選択の全境界と、選択対象が画面外へ出る組合せは自動試験で未網羅。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
