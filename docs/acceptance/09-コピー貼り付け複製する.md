# 枝をコピー・貼り付け・複製する

本文だけでなく配下、メモ、書式、画像を保った新しい枝を作れる。この結果を利用者が画面、再読込、または保存したファイルから確認できることを受け入れ条件とする。

## 操作前の状態

配下、メモ、書式、添付画像を持つ枝を選択している。アプリは本人1人のローカル環境で動作し、同じマップは一つの編集画面で扱う。

## ユーザーの操作

1. コピーを実行し、貼り付け先のトピックを選んで貼り付ける。
2. ページ再読込を挟んだ貼り付けと、別マップへの貼り付けを別々に試す。
3. 同じ元枝で複製を実行し、元と新しい枝を比較する。

## 期待する結果

- 新しいノードIDで配下を複製し、元の枝の内容を変更しない。
- 再読込後も利用可能な標準クリップボードの専用形式から貼り付けられる。
- 画像付きの枝を別マップへ貼ると、貼り付け先に画像を保全し、新しい画像IDで表示できる。

## 失敗・取消・境界で守ること

- 親子を重複選択した場合は最上位の対象だけを複製する。
- 本文欄で文字を選択しているときは通常の文字コピー・貼り付けを妨げない。
- クリップボード権限が使えない場合は制約とアプリ内コピーを案内し、無言で内容を欠かさない。

## 確認方法と現在の状態

専用形式の再読込後貼り付け、配下・メモ保持、別マップの画像新ID、同一マップ複製の試験がある。対応する試験は[e2e/workflow-ux.spec.ts](../../tests/e2e/workflow-ux.spec.ts)、[e2e/node-images.spec.ts](../../tests/e2e/node-images.spec.ts)、[domain.test.ts](../../tests/domain.test.ts)、[images-domain.test.ts](../../tests/images-domain.test.ts)にある。統合後の本番ビルド、Unit/API38試験、Chrome35試験は成功した。以下の未確認範囲を含め、すべての受け入れ条件が合格したと扱うものではない。

他アプリとの全形式往復、コピー元を完全削除した後の貼付、OS別の権限表示は未確認。試験定義があることを、このファイルの全条件が合格したという意味にはしない。実行日時と結果は[検証記録](../verification-results.md)へ残す。
